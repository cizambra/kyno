# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/cizambra/kyno/security/advisories/new).

Include the affected Kyno version or commit, how to reproduce the problem,
and its security impact. Use a minimal example with test credentials. Do
not include live tokens, database passwords, or private constitution data.

Keep vulnerability details out of public issues and pull requests until
a fix or mitigation is available. Use the private report to coordinate
disclosure with the maintainer.

## Supported versions

Before the first release, security fixes target `main`. After launch,
security fixes target the latest released version. Older releases do not
have a separate maintenance branch.
