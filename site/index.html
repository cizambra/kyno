Your agents are playing a bad telephone game.

Kyno holds one versioned source of direction, and your agents pull it before every step. Change the mission once — the very next step runs on it.

$ pip install kyno

The problem

Stale direction is worse than no direction

When goals change, an agent holding the old copy keeps working toward it. Your quality checks make it worse: they review against the same stale copy, and push finished work back toward the obsolete goal.

Kyno removes the copy. Direction lives in one versioned store, every step pulls the version in force, and subscribers hear the moment it changes.

How it works

Three moves, all of them boring on purpose

Pull before every step

An agent binds the direction in force at its step boundary. This block is what lands in its context — the same marker this page carries in its hero.

[kyno:direction constitution=default version=1]
Mission: To help organizations keep
multi-agent systems coherent.
Principles:
- Coherence is the goal
- Stay simple, stay nimble
- We don't judge
…
Recent changes:
- Kyno adopts its own constitution

Push when it changes

Subscribers hear the moment a new version is appended — a hint to pull, never a payload to trust.

{
  "jsonrpc": "2.0",
  "method":
    "notifications/resources/updated",
  "params": {
    "uri": "kyno://constitution/current"
  }
}

Answers carry their version

Ask what changed since the version you knew, and get the delta — so a transcript can always say which direction each step served.

get_changes_since(known_version=0)
→ {
  "current_version": 1,
  "changed": true,
  "mission": "To help organizations
    keep multi-agent systems coherent.",
  …
}

Quick start

Running in a minute

pip install kyno
kyno init-db
kyno set --mission "Ship a lending product people trust" \
         --note "initial constitution"
kyno current
kyno serve --transport stdio    # or --transport http

Building for a framework we don't ship an adapter for, or for another language entirely? The whole contract is one page, and it comes with a checker.
