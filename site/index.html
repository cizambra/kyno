One direction.Every agent.Every step.

Kyno makes direction a first-class runtime primitive for principled judgment in AI agents. Humans set mission and principles; agents use them to judge tradeoffs and pursue the intended outcome. Adapters fetch current direction through MCP before the next step. Kyno works with or without AI governance tools.

Versioned direction

A constitution is a named mission and ordered principles, with a current version and immutable history. Publish a change while the workflow continues.

◉

Direction at each step

Adapters pull before work proceeds. Successful pulls return current direction; failed pulls follow your configured policy.

◇

Version attribution

Record the direction version supplied to each step. Retrieve that mission and principles when reviewing the run.

A reasonable decision. Yesterday's goal.

Your sales agent is pursuing new revenue. You change the priority to retaining customers. Kyno lets you publish that mission and its principles while the workflow continues; the next successful pull supplies the revised direction before the agent's next step.

Start with SQLite and stdio. Add HTTP or your own adapter when the workflow needs it.

~/acme
$ pip install kyno
$ kyno new acme && cd acme
$ kyno db init
$ printf 'constitution_key: default\nmission: Ship a lending product people trust\n' > constitution.yaml
$ kyno apply constitution.yaml --note "initial constitution"
$ kyno serve --transport stdio
